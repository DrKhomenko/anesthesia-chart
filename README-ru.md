# Анестезиологическая карта — веб-версия

Приложение открывается в Safari на iPad и ставится на экран «Домой» как обычная программа. Работает без сети: всё сохраняется прямо на планшете.

Адрес: https://drkhomenko.github.io/anesthesia-chart/

## Как открыть на iPad
1. Откройте ссылку в **Safari** (только Safari, не Chrome).
2. Нажмите «Поделиться» → **«На экран „Домой“»**.
3. Запускайте с иконки. После первого открытия приложение работает и без интернета. Обновления подтягиваются сами, когда есть сеть.

## Что уже работает
- **Список карт** и кнопка «Новая карта».
- **Шапка карты**: пациент, вид, пол, возраст, вес, порода из справочника, владелец, диагноз, операция, аллергии, бригада, ASA 1–5 и «E», исходные показатели и анализы (с проверкой по лимитам клиники), препараты за 24 ч.
- **Время** во всех полях выбирается списком: кнопка «Сейчас», прокрутка вокруг текущего времени и ввод вручную.
- **Доза** выбирается списком (из рамок препарата в справочнике и недавно введённых значений) или вручную.
- **Справочник препаратов** и **справочник пород** — можно пополнить из настроек или прямо из поля карты («+ Добавить „…“ в справочник»). Препараты клиника заполняет сама; короткий стартовый список пород уже есть. Опиоиды и фентанил не запрещены.
- **Лимиты физикальных и лабораторных показателей** в настройках, отдельно для собаки и кошки. Значения приложение не подставляет. Есть отметка «Утверждено: ФИО / дата». В шапке выход за лимит подсвечивается, отсутствие рамок показывается как «не настроено», ничего не блокируется.
- **Проверка веса** на опечатки (как раньше) и автосохранение с историей правок.
- **Премедикация**: выбор препарата из справочника, расчёт мг и мл по весу и концентрации, путь введения, время, повтор дозы, ручная правка объёма с записью в историю, показатели до индукции и заметки.

## Что пока заглушка
Экраны «Индукция», «Поддержание», «Пробуждение». Отправка карт на сервер (синхронизация) тоже будет позже: сейчас всё живёт только на этом iPad.

## Важно
- Приложение **не придумывает дозы, пороги и лимиты анализов**. С бланка заданы только МАД < 60 и T < 36,5 °C. Остальное вписываете вы в «Настройках» и утверждаете.
- Пока нет синхронизации, Safari теоретически может очистить данные сайта, если приложением долго не пользоваться. Приложение просит iPad хранить данные постоянно, но до появления сервера не используйте его как единственный носитель карт.

## Для программиста
Vite + TypeScript + React, IndexedDB через Dexie, офлайн через vite-plugin-pwa (autoUpdate, skipWaiting, clientsClaim), тесты Vitest.
`npm test` · `npm run build` · `npm run preview`.
Логика: `src/core/logic.ts`; база: `src/db/db.ts`; экраны: `src/ui/`. Базовый путь: `/anesthesia-chart/`.
