# Анестезиологическая карта — веб-версия (каркас)

Приложение открывается в Safari на iPad и ставится на экран «Домой» как обычная программа. Работает без сети: всё сохраняется прямо на планшете.

## Как открыть на iPad
1. Откройте ссылку в **Safari** (только Safari, не Chrome).
2. Нажмите «Поделиться» → **«На экран „Домой“»**.
3. Запускайте с иконки. После первого открытия приложение работает и без интернета.

## Что уже работает
- **Список карт** и кнопка «Новая карта».
- **Шапка карты** полностью: пациент, вид (собака/кошка), пол, возраст, вес, порода, владелец, диагноз, операция, аллергии, бригада, ASA 1–5 и «E», исходные показатели, анализы, препараты за 24 ч.
- **Проверка веса**: если вес вне рамок клиники — предупреждение и подсказка («Возможно, лишний ноль: 3,3 кг?»), кнопки «Исправить» и «Вес верный». Пока рамки не заданы, проверка не делается, и приложение прямо об этом пишет.
- **Автосохранение** через полсекунды после каждой правки. Плашка вверху: «Сохраняю…» → «Сохранено на планшете». Рядом видно, есть ли сеть.
- **История правок**: каждое изменение (что было, что стало, когда) записывается.
- **Настройки**: справочник препаратов (название, концентрация, единицы, путь введения, флажок «контролируемый»; можно скрыть или удалить), рамки веса, пороги тревог для собак и кошек.
- **Расчёт доз, тревоги и объём инфузий** уже написаны и проверены тестами, на экраны они попадут на следующих шагах.

## Что пока заглушка
Экраны «Премедикация», «Индукция», «Поддержание», «Пробуждение». Отправка карт на сервер (синхронизация) тоже будет позже: сейчас всё живёт только на этом iPad.

## Важно
- Приложение **не придумывает дозы и пороги**. Заданы только два значения с бумажного бланка: МАД < 60 и T < 36,5 °C. Остальное вписываете вы в «Настройках».
- Пока нет синхронизации, Safari теоретически может очистить данные сайта, если приложением долго не пользоваться. Приложение просит iPad хранить данные постоянно, но до появления сервера не используйте его как единственный носитель карт.
- Текущая ссылка временная, для проверки.

## Для программиста
Vite + TypeScript + React, IndexedDB через Dexie, офлайн через vite-plugin-pwa, тесты Vitest.
`npm install` · `npm test` · `npm run build` · `npm run preview`.
Логика: `src/core/logic.ts`; база и история правок: `src/db/db.ts`; экраны: `src/ui/`.
